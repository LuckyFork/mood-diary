# 心晴日记 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成情绪记录到关怀反馈的使用流程，保留部署地址和远端版本历史。

**Architecture:** 静态 HTML/CSS，core.js 承担存储、校验、筛选、统计和计时；app.js 负责 DOM 与活动交互。GitHub connector 管理远端 Git 对象与分支，避免本机 Git 网络连接故障。

**Tech Stack:** 原生 JavaScript、Node node:test、Chrome CDP，无生产依赖。

**Spec:** docs/superpowers/specs/2026-10-31-care-loop-design.md

## Global Constraints

- 继续使用无依赖静态页面，不增加账户、后端、大模型、追踪或外部媒体请求。
- 保持 https://luckyfork.github.io/mood-diary/ 地址不变。
- 情绪必选，强度 1–5，触发因素和文字选填。
- 不再静默截断记录；仅在持久化成功后更新内存状态。
- 从远端已有提交创建功能分支，保留原始历史，分功能提交，不强推。

## Review Focus

- 旧键存在且新键损坏时不能自动回退后覆盖；Task 1 测试。
- 存储容量耗尽、读取被阻止时保留输入和可恢复原始数据；Task 1 和 2 测试。
- 午夜边界与未来时间不能混入 7/30 天统计；Task 1 测试。
- 示例模式中编辑、删除、反馈、清空不能写入个人数据；Task 2 浏览器测试。
- 暂停、提前退出或切换模式后不得残留计时器/音频或误存完成记录；Task 2 浏览器测试。

**Files:** core.js、tests/core.test.cjs、package.json。
**Interfaces:** loadState(storage) -> {state, error, source}；saveState(storage,state) -> {ok,error}；analyze(state,days,now)；filterEntries(entries,options)；activityProgress(id,elapsedMs)。CommonJS 与浏览器全局共用同一实现。

- [ ] 先写并运行失败测试，覆盖旧数据迁移、损坏数据、写入失败、超过 200 条、日期边界、因素共现、反馈分母、最后一次呼气。
- [ ] 实现接口，纯数据函数不依赖 DOM，不静默覆盖损坏数据。
- [ ] 运行 node --test tests/core.test.cjs，全部通过。
