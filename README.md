# 心晴日记

一个无需登录、个人数据保存在当前浏览器的情绪日记与自我关怀原型。

固定作品地址：<https://luckyfork.github.io/mood-diary/>。迭代时保留该域名和 `/mood-diary/` 路径。

## v2 的使用流程

- **记录此刻**：选择情绪与强度，选填触发因素、文字；支持后续编辑。
- **照顾自己**：可直接开始呼吸、感官觉察、雨声或轻舒展。活动可暂停、继续、提前结束，完成后可以反馈感受或跳过评价。
- **情绪回顾**：近 7/30 个自然日的情绪分布、强度记录、因素共现、活动反馈；点击因素可追溯对应日记。
- **示例模式**：演示记录和反馈仅存在内存，与个人数据隔离，退出时恢复个人草稿。
- **历史与数据**：搜索、筛选、查看更早记录、编辑、删除后 10 秒内撤销，以及 JSON 导出和确认清空。

“相关因素”只描述记录中的共现，不推断因果；活动反馈是主观感受，不是疗效评估。本产品不提供诊断或治疗。

## 本地运行

页面没有生产依赖，也没有构建步骤。用任意静态服务启动项目，例如：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。推荐通过 HTTP 服务访问，避免 `file://` 的浏览器存储差异。

## 验证

需要 Node.js 22 或更高版本；推荐 Node.js 24。

```bash
npm test
npm run test:browser
```

不需要 `npm install`。数据测试使用 `node:test`；浏览器测试通过 CDP 启动独立 Chrome、临时用户目录和本地测试服务，不操作用户现有浏览器或个人日记。

浏览器测试在 macOS 默认使用 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，在 Linux 默认使用 `google-chrome`。可用 `CHROME_PATH` 指定其他安装位置。测试需要本地端口 4173 和 9333；可用 `CDP_PORT` 修改调试端口。截图和测试下载文件写入系统临时目录的 `mood-diary-qa`，可用 `QA_DIR` 覆盖。

GitHub Actions 配置运行语法检查、数据测试和真实 Chrome 流程；不依赖云端 AI 或外部音频服务。

## 数据与迁移

- 当前键名为 `mood-diary-v2`，保存 `{ version: 2, entries, sessions }`。
- 首次读取兼容原来的 `mood-diary-v1` 数组。首次成功写入时创建 v2 数据，旧键保留为迁移备份。
- 旧版长文完整保留；新建文本限制 2000 字，编辑历史长文不会截断。
- 不静默截断历史记录。空间不足或写入被阻止时保留输入并提示失败。
- 无法识别的数据不会自动覆盖，可先下载原始备份，再确认重置。
- 多标签页监听本地数据变更；写入前校验版本，支持 Web Locks 的浏览器还会串行处理写入。检测到冲突时刷新记录并保留草稿，要求用户重新确认保存。旧版页面与新版页面同时打开时，建议刷新旧版页面。
- 清空会删除当前数据和旧版备份，不可撤销。示例模式不能执行个人数据清空。
- 导出文件可用于个人归档；当前没有一键导入界面。更换设备或清除浏览器数据后不会自动同步。
- 日记、练习和音频均在浏览器内处理。雨声通过 Web Audio 生成，不加载远程媒体。网站托管服务仍会收到普通页面资源请求。
